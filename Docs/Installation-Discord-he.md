**התקנת הרובוט 4744 ב־MoSim**

1. סגור את MoSim וחלץ את קובץ ה־ZIP.
2. לחץ `Win + R`, הדבק את הנתיב הבא ולחץ Enter:
   ```text
   %USERPROFILE%\AppData\LocalLow\CascadeStudios\MoSim\Mods
   ```
3. העתק לשם את התיקייה `Ninjas4744-Turbo2026` שחילצת.

   המבנה צריך להיות:
   ```text
   Mods\Ninjas4744-Turbo2026\standalonewindows64\modpack.json
   ```

4. פתח את MoSim. בתפריט **Games** בחר **Rebuilt**, ואז עבור אל **Play → Singleplayer**.
5. לחץ **View Mods**, הפעל את **Ninjas 4744 Turbo 2026**, בחר ברובוט **4744** ולחץ **Start**.

**אם הרובוט לא מופיע:** בדוק שאין תיקייה כפולה בתוך תיקייה, ואז הפעל מחדש את המשחק.

**אם כבר מותקנת גרסה קודמת:** החלף את הקבצים כשהמשחק סגור, והשאר רק עותק אחד של המוד פעיל.
